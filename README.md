# 🎵 Andante (AI 감성 캔버스)

사용자의 '오늘 하루 기분'을 입력받아 AI가 그 감성을 분석하고, 맞춤형 시(Poem), 날씨, 그림(Image), 그리고 힐링 음악(BGM)을 한 번에 추천해 주는 신개념 감성 일기장 웹서비스입니다.

## 🌟 주요 기능
*   **AI 감성 분석:** 일상적인 문장으로 기분을 적으면 AI(Gemini/OpenAI)가 감정을 세밀하게 분석합니다.
*   **시 & 그림 자동 생성:** 분석된 감정에 어울리는 짧은 위로의 시와 감성적인 캔버스 그림이 자동으로 생성됩니다.
*   **힐링 음악 큐레이션:** 감정에 맞는 태그를 기반으로 Jamendo API를 통해 어울리는 음악을 재생합니다.
*   **내 일기장 & 공유 갤러리:** 생성된 결과물을 개인 일기장에 저장하거나, 공용 게시판에 올려 다른 사람들과 감정을 공유할 수 있습니다.

---

## ⚙️ 1. 백엔드 (서버 & 데이터베이스)

*   **`server.js` (핵심 서버 로직)**
    *   Node.js (Express) 기반의 메인 서버 파일입니다.
    *   **역할:** 유저들의 요청을 받아 AI(Gemini, OpenAI 등)에게 시와 그림 생성을 요청하고 그 결과를 프론트엔드로 전달해 줍니다.
    *   **주요 기능:** JWT 기반 로그인/회원가입 처리, Oracle DB 저장/불러오기 API (`/api/diaries`, `/api/boards`), AI 프롬프트 분석 및 이미지 생성 호출.
*   **`connect.js` & `query.js` (DB 연결 모듈)**
    *   Oracle Database와의 안전한 연결을 담당하는 보조 파일들입니다.
    *   **역할:** 서버가 데이터베이스와 통신할 때마다 필요한 다리 역할을 하며, 연결 관리를 수행합니다.
*   **`.env` (환경변수 및 비밀키)**
    *   **역할:** OpenAI, Gemini 외부 API 키, Oracle DB 계정, JWT 암호화 키 등 보안에 민감한 정보들을 안전하게 보관합니다. (Git에는 업로드되지 않습니다)

## 🎨 2. 프론트엔드 (사용자 화면 & 동작)

### 핵심 화면 및 로직
*   **`public/index.html` (메인 화면)**
    *   사용자가 가장 먼저 마주하는 핵심 화면으로, 기분 입력창과 AI 생성 결과창(Wizard View)을 포함합니다.
*   **`public/app.js` (메인 프론트엔드 로직)**
    *   화면을 동적으로 제어하는 가장 중요한 자바스크립트 파일입니다.
    *   **역할:** 기분 데이터 서버 전송, 로딩 애니메이션, 결과물 배치, Jamendo BGM 음악 재생 및 일기장 저장/공유 로직 처리.
*   **`public/style.css` (디자인 스타일시트)**
    *   **역할:** 글래스모피즘(투명한 유리 효과), 브루탈리즘 UI 포인트, 모던한 레이아웃과 감성적인 애니메이션 스타일을 정의합니다.

### 서브 화면들
*   **`public/login.html` (인증 화면)**
    *   사용자의 로그인과 회원가입(이름, 성별, 나이, MBTI 등 추가 정보)을 처리합니다.
*   **`public/mypage.html` (내 일기장)**
    *   자신이 저장했던 과거의 일기(AI 결과물, 이미지, 음악)들을 모아서 보여주는 개인 공간입니다.
*   **`public/board.html` (공유 갤러리)**
    *   다른 유저들이 자랑하고 싶어서 공유한 일기들을 갤러리 형태로 모아서 볼 수 있는 공용 소통 공간입니다.

## 🚀 시작하기 (설치 및 실행)

1. 저장소를 클론(Clone) 받습니다.
   ```bash
   git clone https://github.com/202207014/Andante.git
   ```
2. 패키지를 설치합니다.
   ```bash
   npm install
   ```
3. 프로젝트 최상단 폴더에 `.env` 파일을 생성하고 본인의 API 키와 DB 정보를 입력합니다.
4. 백엔드 서버를 실행합니다.
   ```bash
   node server.js
   ```
5. 브라우저에서 `http://localhost:3000` 으로 접속합니다.
